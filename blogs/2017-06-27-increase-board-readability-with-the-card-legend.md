<p>It is now possible to have the names of the card types used on a board displayed below the board itself, along with their associated card colors. Especially useful if you're working on multiple boards and are having to remember what each color signals within which project.<br />
To start using this helpful legend, simply enable it in board <strong>Settings</strong> - <strong>Power-Ups</strong>.</p>
