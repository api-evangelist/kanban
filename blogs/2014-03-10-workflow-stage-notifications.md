Recently, we have presented you how to automatically copy tasks between different Kanban boards using Zapier. Today, we would like to show you another possibility - how to set up an email notification that is automatically send to your email address when a card is moved to a specified column. It is particularly useful when columns on you board are assigned to team members or to specific company's departments (for example if you are using Heijunka board).
